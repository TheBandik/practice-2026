## Структура репозитория студента

Папка [`student-repo-demo/`](student-repo-demo/) содержит образец репозитория, который студент сдаёт по итогам практики.

## Что нужно сдать

1. **Отчёт** — 20–25 страниц по СК-СТО-ТР-04-1.005-2015
2. **Репозиторий** (GitHub или аналог):
   - Исходный код с декомпозицией на модули
   - Тесты и наборы тестовых данных
   - `Dockerfile`
   - `README.md` с инструкцией по установке, запуску и настройке
